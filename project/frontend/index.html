How Values Are Calculated

Use this as the quick reference for what the app is actually showing. Start with the window, then the selected years, then the mode where applicable.

Climatic Map

The climate raster and the climate cursor tooltip read from the same aggregated tile payload. In this view, Rain means mm/day, and Rain sum is the visible-period total derived from that daily value.

Tour Planning

Tour Planning has no single 24h/Active switch. The station payload carries historical and daytime fields in parallel, and the tooltip, glyph, and profile each use different subsets of that same payload.
